# PULSO visual system
Black OLED canvas, white SF Rounded numerals, mint Codex and lilac Copilot. Native SF Symbols and system forms for settings. Thin horizontal remaining-quota bars, no fake sparkline or activity ticker. Spacious 28pt portrait insets, provider sections divided by a hairline. Landscape puts sections side by side. Muted source/time labels stay visible, stale readings use explicit orange text. Demo banner uses yellow and the word DEMOSTRACIÓN. Desk mode hides system chrome but retains an accessible exit control. Night tone uses red foreground/accent. Main view scrolls for small screens and large text. No motion needed for a passive glanceable dashboard.
