# PULSO Implementation Plan
> Execute with subagent-driven-development; independent integration implementation and review.

**Goal:** Build an iPhone-only SwiftUI quota dashboard with desk mode and StandBy widgets.
**Architecture:** Codable value snapshots shared with WidgetKit; main actor observable UI store; URLSession GitHub adapter and isolated WKWebView Codex session.
**Tech Stack:** Swift 5 language mode, iOS 17+, SwiftUI, WebKit, Security, WidgetKit, XCTest.
**Spec:** docs/superpowers/specs/2026-11-04-pulso-design.md

## Global Constraints
- No Mac bridge, hosted backend, fabricated live activity, or credentials in shared storage.
- Display unknown quotas as unknown; demo must be explicit and never cached for widgets.
- Foreground idle timer restoration; respect system StandBy refresh.

## Review Focus
- Missing or malformed limits must not become zero usage or full remaining.
- Login expiry must preserve last update timestamp and report stale.
- Logout must remove cached data and session credentials.
- Rotation and large text must remain readable and scrollable.
- Widget must mark cached data stale and never expose credentials.
