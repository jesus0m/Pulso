# Claude provider implementation plan

**Goal:** Add Claude subscription session and weekly quotas to the existing iPhone-only PULSO app.
**Architecture:** Dedicated persistent WebKit session on claude.ai, schema-validated same-origin read, existing snapshots/store/widgets.
**Constraints:** Experimental web endpoint; no API-spend/subscription confusion, no inferred per-agent activity, no tokens/cookies in widget cache. Codex logout must not delete Claude session or vice versa. Do not choose an arbitrary organization when multiple exist.
