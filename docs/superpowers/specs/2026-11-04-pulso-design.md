# PULSO
Native SwiftUI iPhone dashboard for Codex and GitHub Copilot usage. Runs entirely on iPhone; no bridge or backend. Approved direction: black background, large readable remaining quota, restrained mint/lilac provider accents, portrait stacked and landscape side by side. Experimental Codex web session integration explicitly accepted. Never fabricate activity, remaining allowance, authentication or freshness.

iOS 17 minimum. Foreground desk mode disables idle timer only while active and restores it on exit/background. Widgets support system StandBy; no guarantee of forced Always-On or second-by-second background updates. Shared app group stores quota snapshots, never credentials. Keychain holds GitHub personal token; Codex uses persistent WKWebsiteDataStore session entirely on device. GitHub token read Plan permission is a first release alternative to OAuth requiring an app registration. Explicit demo available, clearly labelled and isolated from real snapshots.

Copilot: documented user billing usage endpoint, usage credits or legacy premium requests, user-entered allowance with explicit source. Codex: embedded official site login and same-origin usage fetch using web session; parse only validated known rate-limit schemas. Keep web session visible when reconnect is needed. No agent activity inferred from quota data. Status includes disconnected, fetching, fresh, stale, unsupported and error. Secrets never enter logs, UserDefaults or widget cache.
